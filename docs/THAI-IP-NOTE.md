# ข้อจำกัดเครือข่ายและข้อกำหนด Thai IP สำหรับ Grouper API

เอกสารนี้อธิบายข้อกำหนดด้านเครือข่ายในการติดต่อ MOPH DRG Grouper API (`had-api.moph.go.th`)

---

## 1. ข้อจำกัดทางเทคนิคของ MOPH Grouper API

API ของกองเศรษฐกิจสุขภาพและหลักประกันสุขภาพ กระทรวงสาธารณสุข:
- URL หลัก: `https://had-api.moph.go.th/cmi/drg/calculate`
- **การจำกัด IP**: ระบบอนุญาตให้เรียกใช้งานได้เฉพาะจาก **IP Address ภายในประเทศไทยเท่านั้น** (Thailand Geolocation IP)
- หากส่งคำขอจากต่างประเทศ เซิร์ฟเวอร์ปลายทางจะตอบกลับ `404 Not Found` หรือตัดการเชื่อมต่อทันที

---

## 2. นโยบายความปลอดภัยของข้อมูลผู้ป่วย (Zero Proxy Policy)

ตามข้อกำหนดความปลอดภัยของระบบ DRGSeeker และมาตรฐานข้อมูลสารสนเทศสุขภาพ:
> **ห้ามส่งคำขอคำนวณเคส (`POST /drg/calculate`) ผ่าน Public CORS Proxy หรือ Proxy ภายนอกที่ไม่ได้รับอนุญาตโดยเด็ดขาด**

เนื่องจาก Payload มีข้อมูลรหัสการรักษา วันที่นอน อายุ เพศ แม้จะตัดชื่อผู้ป่วยออกแล้วก็ตาม แต่ต้องยิงตรงไปยัง `had-api.moph.go.th` จาก Browser ฝั่งผู้ใช้เท่านั้น (CORS Headers ของกระทรวงฯ เปิด `Access-Control-Allow-Origin: *` สำหรับ endpoint นี้อยู่แล้ว)

---

## 3. คำแนะนำสำหรับนักพัฒนาเมื่ออยู่นอกประเทศไทย (Overseas Development)

หากนักพัฒนาทำงานจากนอกประเทศไทย หรือเชื่อมต่อผ่าน Cloud Runner ต่างประเทศ:
1. **ใช้ VPN / Proxy เครือข่ายไทย**:
   - เชื่อมต่อ VPN ที่มี Exit node อยู่ในประเทศไทย
   - หรือเชื่อมต่อผ่านโรงพยาบาล/กระทรวงสาธารณสุข
2. **ใช้โหมดจำลอง (Demo Mode) ในการทดสอบภายใน**:
   - แอปพลิเคชันถูกออกแบบให้มี Built-in Demo Fixture และ Unit Test Mocks ทำให้สามารถทดสอบและพัฒนาได้ 100% โดยไม่ต้องเชื่อมต่อ API จริง
   - เมื่อรัน Unit Tests (`npm test`) ระบบจะใช้ Mocking ทั้งหมดตาม TDD
